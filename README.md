## 三网优化到底优化了什么

「三网」指电信（AS4134）、联通（AS4837 / AS9929）、移动（AS9808 / AS58453）三家骨干网。国内访问海外 VPS 慢，根子在于跨境国际出口带宽有限，晚高峰三家用户一起抢。「三网优化」就是商家在境外机房分别接入三家各自的优质线路：电信 CN2 GIA（AS4809）、联通 CUII / AS9929、移动 CMIN2（CMI 骨干 AS58453）。

同一条线内部还有档次差：电信 CN2 GIA 强于 CN2 GT，CN2 GT 强于普通 163；联通 AS9929 强于 AS4837；移动 CMIN2 强于普通 CMI。全高端组合是 CN2 GIA + 9929 + CMIN2，价格也最高。

比去程更值得看的是回程。访客打开你的网站，请求从国内发到 VPS 是去程，页面数据从 VPS 传回访客是回程，决定打开速度的是回程。只做去程优化的机器，路由追踪看着漂亮，实际晚高峰照样卡。

还有个现实问题：不同商家对「三网优化」的定义宽严不一，有的三条都是精品网，有的只是保证三家都不绕路。比价站上的标签沿用商家自己的说法，不是实测结果。看到「三网优化」四个字，最好再确认一句它具体走哪条线、优化的是去程还是回程。

## 三个机房怎么选

延迟由物理距离决定：香港 30–50ms，东京 50–80ms，美西 150–180ms。香港机房跑 SSH、远程桌面、跨境办公，操作感和本地机器差别不大；东京在 50–80ms 这一档，日常网页、API 调用够用；洛杉矶 150ms 起步，适合对延迟不敏感但吃带宽和流量的场景，比如建站、图床、视频转存、批量抓取。

同配置的价差值得摆出来：香港 HKG.AS3.Pro.TINY 和东京 TYO.AS3.Pro.TINY 都是 1 核 1GB / 20GB / 500GB / 1Gbps，一个 $39.90，一个 $21.90。多花的 18 美元买的是那 30–50ms 的延迟和香港机房的位置，对远程操作类用途值，对建站不一定值。

带宽怎么定？轻量业务（个人博客、单账号 API、小流量中转）100Mbps 端口加 1TB 流量就够；中等流量站点 4–8TB 比较稳；跑到视频、批量任务、多人协作这类，200Mbps 以上、16TB 起步才不憋屈。这套标准放到 DMIT 身上会发现它给的端口远高于此，入门档就是 1Gbps，中高配 10Gbps，说明它面向的是建站和有一定并发需求的用户，不是拿来省钱的。

## 常见问题

**三网优化和 CN2 GIA 是什么关系？**

CN2 GIA 是三网优化里的电信那一段，两者不是并列概念。有的商家三家各接一条（GIA + 9929 + CMIN2），DMIT 的 Pro 是三家回程都走 CN2 GIA。

**去程优化和回程优化差在哪？**

去程是国内到 VPS，回程是 VPS 回国内。打开网页、拉数据主要吃回程。只优化去程的机器，路由追踪好看，实际晚高峰还是堵。

**端口写着 10Gbps，为什么实际跑不到？**

10Gbps 是机房侧给你的端口上限，跨境实际速度受国际出口和晚高峰拥塞限制。第三方测评在洛杉矶 Pro 上晚高峰单线程三网跑到 784–810Mbps，已经接近千兆，10Gbps 的价值在并发和突发流量。

**月付还是年付？**

DMIT 常规 Pro 档以月付标价为主，年付优惠主要出现在限量活动款上。第一次用建议先月付一个月，确认线路和延迟符合预期再考虑长期。

**买了不满意能退吗？**

现有公开资料没有可核验的统一退款条款，下单前在官网条款页确认。也可以先用最小档试一个月，成本比年付锁死低。
